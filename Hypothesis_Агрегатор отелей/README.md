# Проверка гипотез: Агрегатор отелей

Учебный проект по анализу данных и проверке гипотез.

## Описание

**Задача:** анализ туризма в России и проверка гипотез о динамике.

**Что сделано:**

- подготовка данных (переименование в snake_case, обработка пропусков и типов);
- исследовательский анализ данных (EDA): boxplot по категориям размещения, топ-10 регионов по стоимости турпакетов, линейный график динамики;
- проверка гипотез: средняя стоимость турпакетов 800 млн руб., рост числа поездок по России в 2023 vs 2022.

**Инструменты:** Python (pandas, matplotlib, seaborn, scipy), Jupyter Notebook.

**Навыки:** EDA, проверка гипотез, визуализация, статистические тесты.

## Вывод

Проведён полный цикл анализа данных туристической индустрии России
за 2018–2023 годы.

Ключевые результаты:

- **Средняя стоимость турпакетов** в 2023 году статистически значимо
  превышает 800 млн руб. (результат устойчив и подтверждается на выборке
  без выброса-Москвы).
- **Рост числа турпакетов** по России в 2023 году по сравнению с 2022 годом
  формально не подтверждён статистически (p > 0.05), но наблюдается
  положительная тенденция: +10% к среднему (с 36 970 до 40 650).
- **Рынок высококонцентрирован:** Москва и топ-10 регионов формируют
  основную долю стоимости турпакетов.
- **Внутренний туризм** — драйвер роста, устойчивый к кризисам; зарубежный
  восстанавливается медленно, въездной — в глубоком кризисе с 2020 года.

Полученные результаты могут быть использованы для персонализации сервиса
и разработки маркетинговых стратегий.
