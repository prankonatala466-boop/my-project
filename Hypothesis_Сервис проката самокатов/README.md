# Проверка гипотез: Сервис проката самокатов GoFast

Учебный проект по анализу данных и проверке гипотез.

## Описание

**Задача:** провести анализ данных сервиса проката самокатов GoFast
для выявления закономерностей в поведении пользователей и оценки
потенциальной выгоды от распространения платной подписки.

**Что сделано:**

- загрузка и предобработка данных;
- исследовательский анализ данных (EDA);
- объединение данных о пользователях, поездках и подписках;
- расчёт выручки по месяцам для каждой категории пользователей;
- проверка гипотез о различиях в поведении подписчиков и пользователей без подписки (время и расстояние поездок, помесячная выручка);
- моделирование нормального распределения длительности поездок;
- расчёт доли поездок > 30 мин и 20–30 мин, 90-го процентиля.

**Инструменты:** Python (pandas, matplotlib, scipy), Jupyter Notebook.

**Навыки:** проверка гипотез, t-тест, работа с распределениями,
процентили, интерпретация результатов.

## Вывод

Подписка ultra статистически значимо выгодна: подписчики приносят
больше месячной выручки (+37 руб./мес на пользователя) и ездят дольше,
не превышая критическую дистанцию износа. Наиболее перспективные
направления — продвижение подписки среди аудитории 20–33 лет
и промоакции для поездок длительностью 20–30 минут.
