# EDA: Рынок стартапов

Учебный проект по исследовательскому анализу данных (EDA).

## Описание

**Задача:** исследование закономерностей финансирования стартапов для оценки инвестиционных стратегий.

**Что сделано:**

- предобработка данных (объединение двух датасетов, очистка, работа с пропусками и выбросами);
- группировка компаний по срокам финансирования;
- классификация сегментов рынка на массовые, средние и нишевые;
- анализ типичных и аномальных объёмов финансирования;
- сравнение типов финансирования;
- анализ динамики инвестиций по годам;
- расчёт доли возврата средств по типам финансирования;
- итоговые рекомендации для 2015 года.

**Инструменты:** Python (pandas, matplotlib, seaborn), Jupyter Notebook.

**Навыки:** предобработка, классификация, анализ динамики, инвестиционный анализ.

## Вывод

Проведён полный цикл анализа данных о венчурном финансировании стартапов
(итоговый датасет — 35 589 компаний после очистки от выбросов).

**Сроки финансирования:** компании с финансированием более года составляют
30.3% от общего числа, но привлекают 62.0% всех инвестиций.

**Сегменты рынка:** 73.2% сегментов являются нишевыми, что говорит
о высокой фрагментации рынка. При этом 49 массовых сегментов охватывают
88.6% всех компаний.

**Типы финансирования:** venture — лидер по объёму и популярности
(129.1 млрд USD, 18 821 компания), но имеет самую низкую возвратность
(39.2%). Наилучшую возвратность показывают angel (68.8%),
debt_financing (62.2%) и private_equity (59.2%).

### Рекомендации для инвестора на 2015 год

- **Перспективные сегменты:** Medical, Apps, Internet, Technology —
  все демонстрируют устойчивый рост объёмов инвестиций.
- **Приоритетные типы финансирования:** debt_financing, angel,
  private_equity — сочетают высокую возвратность и стабильность.
- **Избегать:** венчурного финансирования как основного инструмента
  из-за низкой возвратности.
- **Ориентир:** компании с длительным периодом финансирования (> 1 года)
  привлекают 62% всех инвестиций.
- **Учесть:** неполнота данных за 2014 год при планировании.
