# Игровая индустрия. Игра «Секреты темнолесья»

Учебный проект по анализу данных.

## Описание

**Задача:** познакомиться с данными, проверить их корректность
и провести предобработку, получив необходимый срез данных.
Перед анализом необходимо:

- отобрать данные по времени выхода игры (период с 2000 по 2013 год включительно);
- категоризовать игры по оценкам пользователей и экспертов;
- выделить три категории: высокая оценка, средняя оценка, низкая оценка;
- выделить топ-7 платформ.

**Что сделано:**

- загрузка и знакомство с данными;
- проверка типов, пропусков, дубликатов;
- нормализация текста;
- фильтрация по годам (2000–2013);
- категоризация по оценкам пользователей и критиков;
- выделение топ-7 платформ.

**Инструменты:** Python (pandas), Jupyter Notebook.

**Навыки:** предобработка, категоризация, фильтрация,
работа с пропусками и дубликатами.
