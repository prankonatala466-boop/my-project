# Секреты темнолесья

Учебный проект по анализу данных.

## Описание
Задача: предобработка данных об играх для дальнейшего анализа.
Что сделано: загрузка и знакомство с данными, проверка типов, пропусков, дубликатов, нормализация текста, фильтрация по годам (2000–2013), категоризация по оценкам пользователей и критиков, выделение топ-7 платформ.
Инструменты: Python (pandas), Jupyter Notebook.
Навыки: предобработка, категоризация, фильтрация, работа с пропусками и дубликатами.
